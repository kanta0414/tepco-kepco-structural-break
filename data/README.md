# data/

## SCmonthly.csv

東京電力・関西電力・TOPIX の月次データ（2003年9月〜2020年10月、206行）。
大学の講義で配布されたデータを、再現性のためにそのまま同梱しています。

| 列 | 内容 | 単位 |
|---|---|---|
| `ym` | 年-月（例: `11-Mar` = 2011年3月。**年は下2桁**） | 文字列 |
| `TOPIX` | 東証株価指数 | ポイント（円ではない） |
| `KYTB` | 銘柄株価（本分析では未使用） | 円/株 |
| `TKYD` | 東京電力の株価 | 円/株 |
| `KNSD` | 関西電力の株価 | 円/株 |

- 欠損値なし。月の欠落なし（2003年9月〜2020年10月の206か月が連続）。
- 配当は含まない値上がり益ベースの系列です。
- 株価・指数の権利は各権利者（TOPIX は株式会社JPX総研／株式会社東京証券取引所）に帰属します。
  データは学習・再現目的でのみ掲載しており、リポジトリの MIT ライセンスは**コードにのみ**適用されます。
  権利者からの要請があった場合は削除します。
