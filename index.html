電力株の構造変化

東日本大震災の前後で、東京電力・関西電力の株価と市場全体の関係はどう変わったか。月次205か月のデータで、市場感応度（ベータ）の変化を統計的に検証しました。

結果　市場感応度 β：震災前 → 震災後

東京電力0.14→1.83構造変化の検定 p = 0.00005
関西電力0.05→0.87構造変化の検定 p = 0.00044

期間別の回帰による推定値（震災前 n = 89、震災後 n = 116）。震災前のβは両社とも0と区別できません。

分かったこと

震災前の電力株は、市場が動いてもほとんど反応しませんでした。震災後は市場に連動して動く、通常の株式に近い性質へ変わりました。変わったのは水準ではなく、市場との関係そのものです。

直接被災していない関西電力にも同じ変化が出ています。東京電力固有の事故ではなく、原発停止と規制の見直しを通じた電力業界全体の変化だと解釈しました。

やったこと

手法
株価を対数収益率に変換し、市場収益率（TOPIX）で説明する回帰に、震災後ダミーと交差項を加えました。ダミーで1本の式にまとめることで、ベータの差そのものに標準誤差がつき、検定できます。
検証
結果を疑うため、頑健標準誤差（White / Newey-West）、暴落月（2011年3月、東京電力 −78%）の除外、断点の移動を試しました。いずれも結論は変わりません。震災後に誤差分散が13.5倍になっている点も確認しています。
実装
R と Python の両方で実装し、44件のテストで係数・標準誤差・検定統計量が一致することを確認しています。

限界

  • 相関の分析であり、震災が原因だと厳密に証明したものではありません。同時期の欧州債務危機や政権交代の影響は分離していません。
  • 暴落月を除くと東京電力の変化幅は1.69から1.20に縮みます。ベータの上昇は残りますが、推定値の大きさの一部はこの1点に依存します。
  • 対象は2社のみです。他の電力会社や、原発を持たない公益企業との比較は未実施です。
