## 5. 機能要件

R のセクション番号と 1 対 1 で対応させる。変数名も R にそろえる（`x, y1, y2, d, dx, q, n`）。

### FR-0 データの読み込み

- `data/SCmonthly.csv` を読み込み、先頭と末尾の数行を表示する。
- 行数が 206、欠損が 0 であることを assert で確認する。

### FR-1 収益率への変換

- `x = diff(log(TOPIX))`、`y1 = diff(log(TKYD))`、`y2 = diff(log(KNSD))`
- 収益率に対応する月ラベルは `ym` の2行目以降とする。
- n = 205 であることを確認する。

### FR-2 ダミー変数

- 震災月は **月ラベルが `"11-Mar"` の位置を検索して求める**。インデックスを直接書き込まない。
- `d` は震災月以降が 1、それより前が 0。`dx = d * x`。
- 震災前 89 件、震災後 116 件であることを確認する。
- **インデックスの違いに注意**：R では `q = 90`（1始まり）、Python では `q = 89`（0始まり）になる。§7 の P-2 参照。

### FR-3 図

- **図A（3×2）**：左の列に株価水準（東京電力、関西電力、TOPIX）、右の列に対数収益率。すべての図に震災時点の赤い破線を引き、収益率の図には 0 の水平線も引く。
- **図B（1×2）**：TOPIX 収益率と各社収益率の散布図。震災前は青の白抜き、震災後は赤の塗りつぶしで描き、期間ごとの回帰直線を重ねる。
- 横軸は年を小数で表したもの（例：2011年3月 → 2011 + 2/12）。
- ラベルは日本語で、文字化けしないこと。

### FR-4 記述統計

- TOPIX、TKYD、KNSD のそれぞれについて、全期間・震災前・震災後の9行を出す。
- 列は n、平均、標準偏差（不偏分散による）、最小、最大。小数4桁に丸めて表示する。

### FR-5 モデル比較

- R の `compare()` と同じ 10 モデルを、各社について推定する。

| ラベル | 説明変数 | 定数項 |
|---|---|---|
| `a` | なし | あり |
| `a+bx` | x | あり |
| `a+cd+bx` | d, x | あり |
| `a+bx+g dx` | x, dx | あり |
| `a+cd+bx+g dx` | d, x, dx | あり |
| `a+cd+g dx` | d, dx | あり |
| `bx+g dx` | x, dx | なし |
| `cd+bx+g dx` | d, x, dx | なし |
| `cd+g dx` | d, dx | なし |
| `g dx` | dx | なし |

- 表に出す列は k（係数の数）、修正済み R²、σ、AIC。修正済み R² の降順で並べる。
- **修正済み R² は中心化 TSS で自前計算する**：`1 − (RSS/(n−k)) / (TSS_c/(n−1))`（§7 の P-3 参照）。
- **AIC は R の `AIC()` と同じ値にする**（§7 の P-4 参照）。

### FR-6 主要モデルの推定

各社について次の3モデルを推定し、係数・標準誤差・t 値・p 値・修正済み R² を表示する。

- 構造変化なし：`y ~ x`
- 完全モデル：`y ~ d + x + dx`
- 縮約モデル：`y ~ d + dx`（定数項なし）

### FR-7 構造変化の検定

- Chow 検定：「構造変化なし」と「完全モデル」を F 検定で比べる。表示内容は R の `anova()` と同じ（残差の自由度、RSS、F、p）。
- 期間別の推定：震災前と震災後それぞれで `y ~ x` を推定し、係数表を出す。

### FR-8 頑健性チェック

| ID | 内容 | 要件 |
|---|---|---|
| FR-8a | 頑健標準誤差 | 完全モデルについて、係数、OLS の SE、HC1 の SE と t 値、HAC（ラグ4）の SE・t 値・p 値を1つの表にまとめる。p 値は正規近似 |
| FR-8b | 分散比の検定 | R の `var.test` に相当する処理（震災後の分散 / 震災前の分散、両側 p 値）を TKYD・KNSD・TOPIX に対して行う |
| FR-8c | 2011年3月を除く | 完全モデルを n = 204 で推定し直す |
| FR-8d | 2011年3〜12月を除く | 完全モデルを n = 195 で推定し直す |
| FR-8e | 断点をずらす | 断点を震災月の −2〜+2 か月にずらし、それぞれの完全モデルの修正済み R²（中心化）を1行で出す |

### FR-9 ステップワイズ選択

- 前進選択。出発点は `y ~ 1`、候補は x, d, dx。
- 評価基準は R の `extractAIC` と同じ `n·log(RSS/n) + 2k`。
- 各ステップで候補ごとの自由度、平方和の減少分、RSS、AIC を表示する（R の `stepAIC` の出力に合わせる）。
- AIC が改善しなくなったら止め、最終モデルと係数を表示する。

## 7. 実装上の注意（R と Python の違い）

**検証で実際にずれを確認した項目**。そのまま実装すると R と数値が合わなくなる。

| ID | 違い | 検証で起きたこと | 対処 |
|---|---|---|---|
| **P-1** | 日付のパース | `ym` は `"3-Sep"` のように年が1桁。`pd.to_datetime(format="%y-%b")` も `datetime.strptime` も **ValueError** になった | `"-"` で分割し、年 = 2000 + 整数、月は略称の対応表で変換する（R 版と同じやり方） |
| **P-2** | インデックスの始まり | 震災月は R では 90、Python では 89 | ラベル検索で求めるので値は自動的に合う。ただし表示やコメントでは「R では 90」と併記する。除外範囲 `q:(q+9)` は Python では `q, …, q+9`（10件）になるよう注意する |
| **P-3** | 定数項なしモデルの R² | statsmodels の `rsquared_adj` も R と同じく**非中心化 TSS** を使う。KNSD の `d, dx` モデルで statsmodels は 0.1423、中心化で計算すると 0.1450 | FR-5 の式で自前計算する。`rsquared_adj` はモデル比較に使わない |
| **P-4** | AIC の定義 | statsmodels の `aic` は σ をパラメータに数えないため、R の `AIC()` より **2 小さい**（完全モデルで −225.72 と −223.72） | R の `AIC()` に合わせるなら `aic + 2` を使う。どちらを使っても順位は変わらない |
| **P-5** | HAC の小標本補正 | `cov_type="HAC", maxlags=4` のままだと SE が 0.56158 になり、R の 0.56714 と合わない | `use_correction=True` を指定すると一致する |
| **P-6** | stepAIC がない | statsmodels には前進ステップワイズの関数がない | FR-9 の基準で自前実装する。statsmodels の `aic` は定義が違う（P-4）ので使わない |
| **P-7** | var.test がない | SciPy に同じ名前の関数はない | `stats.f` で F 統計量と両側 p 値を計算する。TKYD の p 値は R では `< 2.2e-16` と表示されるが、Python では実際の値（7.95e-29）が出る。表示の違いだけで結果は同じ |

**そのままで一致した項目**（特別な対処はいらない）

- `sm.OLS` の係数と標準誤差
- `anova_lm` や `compare_f_test` による Chow 検定
- `cov_type="HC1"`
- `het_breuschpagan` の既定（Koenker 版）
- `acorr_breusch_godfrey(nlags=4)`
- `durbin_watson`

## 付録：R と Python の対応表

| 処理 | R | Python |
|---|---|---|
| CSV の読み込み | `read.csv()` | `pd.read_csv()` |
| 対数差分 | `diff(log(v))` | `np.diff(np.log(v))` |
| OLS | `lm(y ~ d + x + dx)` | `sm.OLS(y, sm.add_constant(np.column_stack([d, x, dx]))).fit()` |
| 定数項なし | `lm(y ~ d + dx - 1)` | `sm.OLS(y, np.column_stack([d, dx])).fit()` |
| 係数表 | `summary(m)$coefficients` | `m.params`, `m.bse`, `m.tvalues`, `m.pvalues` |
| σ | `summary(m)$sigma` | `np.sqrt(m.scale)` |
| AIC | `AIC(m)` | `m.aic + 2`（P-4） |
| Chow 検定 | `anova(m0, m1)` | `anova_lm(m0, m1)` |
| HC1 | 自前実装 | `m.get_robustcov_results(cov_type="HC1")` |
| Newey–West | 自前実装 | `cov_type="HAC", maxlags=4, use_correction=True`（P-5） |
| 分散比の検定 | `var.test()` | `scipy.stats.f` で自前実装（P-7） |
| 前進ステップワイズ | `MASS::stepAIC()` | 自前実装（P-6） |
| 図の分割 | `par(mfcol = c(3, 2))` | `plt.subplots(3, 2)`。R の mfcol は列方向に埋める点に注意 |
| 日本語フォント | `quartzFonts()` | `plt.rcParams["font.family"] = "Hiragino Sans"` |
